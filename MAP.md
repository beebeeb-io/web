# Module map

This is the index. Each directory below has its own `MAP.md` listing every module it holds,
one line per module: its purpose and its public API. The directory maps are generated by
`map.ts --write`; this index is the one hand-written page (the full 696-row map is far over the
2,000-token cap, and a truncated map is a wrong map).

Start at the directory nearest the thing you are looking for, then follow the module path.
