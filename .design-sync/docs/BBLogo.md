The beebeeb.io wordmark as text: "beebeeb" in the ink colour with an amber ".io". `size` is the font size in px (the app chrome uses 14); `light` renders it white for dark surfaces. To name a product, use `BBProductLockup` (the product icon, "Beebeeb" and the product name) instead of putting a label next to this wordmark; never recolour either.

```tsx
<BBLogo size={14} />
```
