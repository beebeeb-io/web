The beebeeb.io wordmark as text: "beebeeb" in the ink colour with an amber ".io". `size` is the font size in px (the app chrome uses 14); `light` renders it white for dark surfaces. To name a product, use `BBProductLockup` (the product icon, this wordmark and the product name underneath it) instead of putting a label next to the wordmark yourself; never recolour either.

```tsx
<BBLogo size={14} />
```
